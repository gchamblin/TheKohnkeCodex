# The Kohnke Codex

## View the manual

Open `index.html` in a current desktop browser such as Microsoft Edge, Chrome, or Firefox. The page works offline: its styles, scripts, and all 13 photos are included in the HTML file, and it does not need an internet connection or an installation.

## Share it

- Send `index.html` by itself, or send `TheKohnkeCodex-Offline.zip`.
- If sharing through OneDrive or another cloud drive, share the ZIP or HTML file and have the recipient download it.
- The recipient should extract the ZIP if needed, then open `index.html` in their browser. A cloud-drive preview may not run the interactive features.

The `images/` folder and `test.html` are not required to view the standalone manual.
