# Kohnke’s Guide to Grass & Glory

## View the manual

Open `index.html` in a current desktop browser such as Microsoft Edge, Chrome, or Firefox. The page and its pictures are all contained in that one file. It works offline and does not need an installation.

## Share it

- Send `index.html` by itself, or send `Kohnkes-Guide-to-Grass-and-Glory.zip`.
- If sharing through OneDrive or another cloud drive, have the recipient download the file first. A cloud-drive preview may not run the interactive features.
- If sending the ZIP, the recipient extracts it and opens `index.html` in their browser.
