# The Kohnke Codex

## View the manual

Extract the project ZIP, then open `index.html` in a current desktop browser such as Microsoft Edge, Chrome, or Firefox. The page works offline and does not need an installation. Keep the `images/` folder beside `index.html`; the page loads its pictures from that folder.

## Share it

- Send the complete project ZIP. It contains `index.html`, this README, and the images required by the page.
- If sharing through OneDrive or another cloud drive, share the ZIP and have the recipient download and extract it.
- The recipient should open `index.html` in their browser. A cloud-drive preview may not run the interactive features.
